# 课堂互动设计指南

设计互动前加载本文件。面向商科、经济、社科课堂，覆盖四类互动形式；其他学科沿用同一设计逻辑，替换专业示例即可。

## 通用设计原则

1. **紧贴本页**：互动必须依托该页的具体概念、图表或案例，避免「通用综合题」式空泛提问。
2. **一题一目的**：每道题只考察一个核心点，学生 1–5 分钟内可完成。
3. **答案先行**：写题时同步确定答案；答案要具体到可判定对错，开放题给出可对照的要点。
4. **术语用英文**：题目中的概念名称用英文（如 `elasticity`、`GDP`），题干与答案用中文。
5. **难度递进**：一讲内从概念辨认 → 计算/应用 → 开放讨论逐步升级。
6. **密度**：平均每页到每两页一次；内容少的页合并，内容密的页可每页一次；合并时标题写「第 X–Y 页」。

## 四类互动

### 1. 概念提问 + 参考答案

适合定义、区分、判断类知识点。

- **设计要点**：问「是什么 / 有什么区别 / 这个说法对吗及为什么」；避免只问背诵原文。
- **商科/经济示例**：
  - 区分 `accounting profit` 与 `economic profit`：为什么经济利润要减去 implicit cost？
  - 判断正误：「`inflation` 上升时，名义利率一定上升。」（答案：不一定，需区分 `nominal` 与 `real interest rate`，由 Fisher effect 说明。）
  - 概念辨析：`comparative advantage` 与 `absolute advantage` 有何不同？
- **社科示例**：区分 `socialization` 与 `social control`；判断某说法是否属于 `confirmation bias`。
- **答案写法**：给结论 + 一句理由 + 常见误区提醒（如「只看次优选项，不是所有放弃项」）。

### 2. 小练习 / 计算题

适合公式、模型、图表读数类知识点。

- **设计要点**：数字简洁，步骤可控；材料有公式时优先用它。
- **经济示例**：
  - `price elasticity of demand`：价格由 10 涨到 12，需求量由 100 降到 80，用中点法求弹性并判断 demand 是 elastic 还是 inelastic。
  - `GDP`：给出消费、投资、政府购买、净出口数据，用支出法计算 GDP。
  - `opportunity cost`：根据 PPF 上两点计算多生产一单位产品的机会成本。
- **商科示例**：`break-even point` = 固定成本 ÷（单价 − 单位变动成本）；`ROI`、`payback period` 的简单计算。
- **社科示例**：根据调查数据计算 `percentage change`、解读 `correlation` 数值，或计算 `unemployment rate`。
- **答案写法**：列出关键步骤与代入过程，再给结果和单位；可附一句结果含义解读。

### 3. 小组讨论 / 开放题

适合规范、政策、伦理、争议性议题。

- **设计要点**：没有唯一答案，但要给讨论边界和产出形式（如「列出三条论据并说明理由」）。
- **经济示例**：「最低工资上调是否能改善低收入群体处境？」引导用 `price floor`、`surplus`、`elasticity of labor demand` 分析，兼顾效率与公平。
- **商科示例**：「公司是否应进入某新兴市场？」引导用 `SWOT`、成本收益、利益相关者视角。
- **社科示例**：「社交媒体是否削弱了政治参与的质量？」引导从 `social capital`、`agenda setting` 等角度讨论。
- **答案写法**：给 2–4 条参考要点 + 一个示范表态示例，注明「言之成理即可」。

### 4. 情境应用 / 举例迁移

适合把概念用于新情境、连接生活或后续内容。

- **设计要点**：给出具体场景，要求用本页概念解释或预测；场景要贴近学生生活或时事。
- **经济示例**：「咖啡涨价后学生改喝奶茶，这体现了什么？若奶茶也涨价呢？」引导用 `substitutes`、`income effect`、`substitution effect`。
- **商科示例**：「奶茶店第二杯半价，用 `price discrimination` 或 `bundling` 解释其逻辑。」
- **社科示例**：「用 `social stratification` 解释为何不同社区的教育资源不同。」
- **答案写法**：给参考解释 + 可迁移的通用思路（「遇到类似情境时先判断 X，再看 Y」）。

## 质量检查清单

输出互动前逐项自查：

- [ ] 每页或每两页有一次互动，位置紧跟对应知识点
- [ ] 四类形式交替使用，不是全篇同一种
- [ ] 题干中的术语用英文，题干与答案用中文
- [ ] 每题都有参考答案 / 引导方向，计算题有关键步骤
- [ ] 题目依托材料具体内容，且学生可在课堂内完成
- [ ] 没有出现教材中不存在的核心结论（补充例子不算）
